# Design

Use a single native fullscreen owner: dashboard or observations. The header control and F toggle the complete dashboard; the footer control expands observations and requests native fullscreen. The mode and `fullscreenchange` event keep both buttons accurate after Escape or browser exit. The observation layout still retains the header.

Keep the thread footer to one line. Append a compact compaction count after model when reported. Keep source freshness and coverage in the existing accessible card description and instrument titles, without the abbreviated visual row.

The weekly reading retains its percentage and gauge. A smaller signed percentage-point difference from elapsed weekly time appears beside it, green ahead and red behind. Unknown reset or balance yields no variance. Exact semantics remain in the accessible label and title.
