# Design

Hash each machine/thread identity into a deterministic sweep period and offset; derive delays from monotonic time so redraws and reordering cannot reset or resynchronise animations. Shared duration/phase logic drives machine core and sweep plus thread ECG highlights. Motion denotes reported working status, not measured throughput.

Allowlist numeric revision and state_change_seq, plus focused, interactive_ready and launch_pending booleans. Missing, malformed and unsafe integers remain unavailable. Do not copy custom tokens, labels, sessions, paths or terminal data. Propagate the same typed technical object and protocol through validated Work feeds only after classification. Revision and sequence values are Herdr metadata, not token/tool-call counters.

Add compact agent telemetry strips and machine protocol/sample-age fields, terminal-style event rows, subtle static scanlines and corner accents within existing grid/card geometry. Preserve Omarchy colours. Browser geometry checks cover 720p and 1080p. Consolidate Docker installation, operation, rollback, restart and disclosure information into README; deploy/README links to that canonical guide.
