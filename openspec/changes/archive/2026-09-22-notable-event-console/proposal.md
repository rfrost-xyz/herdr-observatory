# Proposal
## Why
Routine poll and pane records overwhelm the CLI; frequent full-screen effects interrupt reading. The CLI needs more space and concise noteworthy events with occasional contextual artwork.
## What Changes
- Set the full-screen FX hold default to 120 seconds, retaining one-second keyboard control.
- Emit concise state/lifecycle/source events only; keep routine telemetry in the live table.
- Expand the CLI to 24 rows with local arrival effects and occasional dynamic project-name artwork.
## Capabilities
### New Capabilities
None.
### Modified Capabilities
- `office-display`: slower full-scene cadence and event-focused scrolling console.
## Impact
Browser composition/event formatting, bundled character artwork, fallback layout, defaults, documentation and tests. No new socket method or disclosure permission.
