## Thread composition

A card has a strong project/state header, compact identity, one activity line, two visual telemetry modules and a small source-age rail. Context uses its reported capacity ratio. Cache uses only validated session input composition. Input/output counts remain labelled but receive less space than the gauges. Partial coverage uses a short visible cue and full accessible detail. Work/Idle/Blocked/Done use theme roles and state-driven motion; no invented activity is animated.

The full-screen grid is four columns by two rows on 16:9 and 16:10 widths at or above 1280px. Cards use available row height rather than intrinsic text height; low-priority labels collapse in the compact variant. A fixed eight-card page does not scroll. Narrow tiles may scroll their own content.

## Allowance composition

The reported remaining percentage fills one weekly bar. A marker on that same bar shows the percentage of the seven-day window remaining. Pace is their difference in percentage points, labelled reserve/deficit/on pace. It is a time-budget comparison, not a projected exhaustion time. It is unknown without a fresh, future reset inside a seven-day window. A compact histogram uses only reported daily token buckets, and explicitly names its observed-day count and total. No missing date becomes zero and tokens never become a quota. Reset passes retain distinct expiry and sample age. Both browser renderers share one validated view model.
