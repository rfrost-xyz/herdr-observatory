# Streaming terminal feed

## Why
A milestone-only transcript is too quiet. The user requests continuously arriving information and visible rippling, crumbling text and glitches while thread state stays clear.

## What Changes
Stream bounded records from every fresh collector capture, staggered for readability. Distinguish SAMPLE/PANE observations from state milestones. Add moving feed field, signal tearing and outgoing glyph fragmentation. Keep thread rows stable and readable.

## Capabilities
### Modified Capabilities
- office-display: rolling sampled information and protected thread state.

## Impact
Browser rendering, UI tests and documentation. Existing read-only collection, deployment and Work privacy boundaries remain.
