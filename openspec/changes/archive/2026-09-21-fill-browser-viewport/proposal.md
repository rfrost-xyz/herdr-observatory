# Proposal
## Why
Font-measured columns underfill the browser even though the canvas fills it.
## What Changes
- Fit the complete terminal grid to the viewport with small fixed edges.
- Use identical cell positions for live text and effects.
## Capabilities
### New Capabilities
None.
### Modified Capabilities
- `office-display`: occupy the available browser viewport.
## Impact
Browser geometry and CSS only; no data or disclosure changes.
