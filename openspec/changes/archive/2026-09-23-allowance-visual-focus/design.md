## Layout

Each card leads with the weekly percentage and a full-width bar. The bar uses the same value as the reported weekly allowance. A second visual compares average used percentage points per day (`Burn`) with even-use percentage points per day available until reset (`Room`); their bars share a scale within the card. The cue says whether burn currently exceeds room. It is a comparison of observed rates, not a prediction or a token conversion.

Reset timing and nonzero reset passes remain compact supporting text. Sample age and full pass details remain available through the accessible summary and tooltip. Unknown values retain a dash and no filled bar. React and fallback renderers use the same view model.

The existing daily token buckets remain in the private feed for later uses. The account card no longer shows a large daily total or historical sparkline because those values cannot establish tokens remaining in the weekly allowance.
