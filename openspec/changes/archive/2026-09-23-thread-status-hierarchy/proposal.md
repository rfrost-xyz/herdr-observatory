# Thread status hierarchy

## Why

The current three equal instruments use a second dial for cached input, while the native status, activity and tool compete for attention. Identity also takes a separate line from the project name. This wastes the small card area at eight threads.

## What changes

- Put the compact harness, host and pane identity beside the project name.
- Give native status and current activity/tool a prominent shared group without confusing hook activity with native state.
- Keep one dial for context. Give session input/output and cached input share equal-sized, readable blocks.
- Preserve the existing source scopes, unknown values and exact accessible detail.

## Impact

Presentation-only changes to both browser renderers and stylesheet. No feed or telemetry schema change.
