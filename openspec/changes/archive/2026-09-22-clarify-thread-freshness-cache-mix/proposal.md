## Why
One card-wide last-known state can make fresh Pi context look old when the last response is old. The input balance groups cache writes under Other and its percentage label does not name the denominator. Old tool activity can read like current work.

## What Changes
- Give hook activity and numeric usage separate ages and source-specific last-known styling.
- Word old activity as a dated observation while preserving Herdr's current state.
- Name total input in the cache-read percentage and show cache writes as a third labelled input part.
- Improve compact card label sizes for the target 720p display.

## Capabilities
### Modified Capabilities
- `activity-dashboard`: card freshness, cache balance and compact presentation.

## Impact
Browser view and documentation only. Existing metadata, hook registration, privacy filters and service topology remain unchanged.
