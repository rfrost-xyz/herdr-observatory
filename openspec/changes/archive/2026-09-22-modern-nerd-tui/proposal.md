# Proposal
## Why
The ASCII-framed terminal still resembles DOS output. It needs a contemporary TUI hierarchy and reliable Nerd Font glyphs across browsers.
## What Changes
- Bundle a licensed Nerd Font and load it locally for live and animated text.
- Replace ASCII framing with Unicode rules, glyph-led states, restrained themed row treatments and compact key hints.
- Preserve readable thread state, scrolling observations, sparse artwork and whole-terminal effects.
## Capabilities
### New Capabilities
None.
### Modified Capabilities
- `office-display`: modern glyph-capable terminal presentation with readable fallback.
## Impact
Browser styling/composition, static asset allowlist, Docker font packaging, documentation and UI/asset verification. No collector or disclosure changes.
