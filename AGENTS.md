# Herdr Observatory

Collectors are read-only. Explicitly installed harness reporters may write only owned, expiring presentation metadata through pane.report_metadata; never lifecycle or session authority. Never send input to Herdr or expose raw terminal output.
Work disclosure is a server boundary, not a UI filter. Unknown projects are Personal.
Use Python 3.11+ standard library and browser-native assets, with the vendored, checksum-pinned browser WebAssembly renderer; no runtime package installation.
Run `python -m unittest discover -s tests -v`, `node --check web/app.js`, `node --test tests/test_ui.cjs tests/test_wasm.mjs` and `openspec validate --all --strict`.
Keep metric scope, sampled history and offline states explicit. Do not commit private configuration or live snapshots.
