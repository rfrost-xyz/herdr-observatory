# Herdr Observatory

Read-only collectors only. Never send input to Herdr or expose raw terminal output.
Work disclosure is a server boundary, not a UI filter. Unknown projects are Personal.
Use Python 3.11+ standard library and browser-native assets; no runtime package installation.
Run `python -m unittest discover -s tests -v`, `node --check web/app.js` and `openspec validate --all --strict`.
Keep metric scope, sampled history and offline states explicit. Do not commit private configuration or live snapshots.
